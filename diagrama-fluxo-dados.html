🏥 Remédio Já - Fluxo de Dados

Diagrama completo do processamento OCR com Google Vision API

1
📱 Interface do Usuário (React Native)
1
Permissões de Câmera
O usuário toca no botão de scan e o app verifica as permissões de câmera usando Expo ImagePicker.
Expo.ImagePicker.requestCameraPermissionsAsync()
2
Captura de Imagem
Abre a câmera nativa do dispositivo para capturar a foto da receita médica ou caixa de remédio.
ImagePicker.launchCameraAsync({ base64: true })
3
Codificação Base64
A imagem capturada é automaticamente convertida para formato Base64 para transmissão via API.
result.assets[0].base64
2
🔍 Processamento OCR (OCRUtils)
4
Preparação da Requisição
O OCRUtils prepara a requisição para a Google Vision API com configurações específicas para detecção de texto.
scanMedicineFromImage(imageUri)
5
Configuração de Features
Define features como TEXT_DETECTION e DOCUMENT_TEXT_DETECTION com maxResults: 50 para capturar todo o texto.
features: [{ type: "TEXT_DETECTION", maxResults: 50 }]

3
🤖 Google Cloud Vision API v1
6
Processamento IA
A API Google processa a imagem usando machine learning para extrair todo o texto visível com alta precisão.
POST https://vision.googleapis.com/v1/images:annotate
7
Extração de Texto
Retorna arrays de textAnnotations com texto extraído, coordenadas boundingPoly e níveis de confiança.
response.textAnnotations[0].description

📊 Formato de Resposta da Google Vision API:

{ "responses": [{ "textAnnotations": [{ "description": "Dipirona 500mg\nTomar 1 comprimido...", "boundingPoly": { "vertices": [{"x": 100, "y": 50}, ...] } }], "fullTextAnnotation": { "text": "Texto completo extraído...", "pages": [...] } }] }
4
⚙️ Processamento Local de Dados
8
Análise de Texto
O app processa o texto extraído procurando por nomes de medicamentos usando expressões regulares e algoritmos de similaridade.
findMedicineInText(extractedText)
9
Estruturação de Dados
Organiza os resultados com nome do medicamento, dosagem, confiança do OCR e metadados adicionais.
processGoogleVisionResponse(response)
10
Armazenamento Local
Salva os resultados no AsyncStorage para histórico e acesso offline usando OCRDataManager.
AsyncStorage.setItem('@ocr_results', JSON.stringify(data))
5
🌐 Consulta à API Local (Axios)
11
Busca por Medicamentos
Com o nome do medicamento identificado, faz requisição Axios para a API local buscar disponibilidade nas unidades de saúde.
medicinesService.searchMedicines(medicineName)
12
Consulta de Unidades
A API consulta o banco SQLite local retornando lista de unidades de saúde que possuem o medicamento em estoque.
GET /api/medicines/search?q={medicineName}

📊 Apresentação dos Resultados
13
Atualização da UI
O HomeScreen atualiza o estado com setBusca() exibindo os resultados na interface do usuário.

14
Feedback Visual

Navegação
Usuário pode navegar para DetailScreen ou MapScreen para ver mais informações sobre as unidades encontradas.
navigation.navigate('DetailScreen', { medicine })

⚠️ Tratamento de Erros

Falhas de Rede
Axios interceptors capturam erros de conexão e exibem mensagens amigáveis ao usuário.
OCR Sem Resultados
Quando nenhum medicamento é detectado, sugere nova captura ou digitação manual.
API Indisponível
Fallback para dados em cache no AsyncStorage quando a API local está offline.
